Carolina Conte: auditing my own portfolio into a token system

My portfolio grew one section at a time, and its CSS shows it. I audited every value in the stylesheet and designed the token system that replaces 58 loose colors, 22 font sizes, and 8 radii with a small set of named decisions.

The audit

Nine variables, and everything else

The site started with nine CSS variables: paper, ink, an accent, one radius. Then came a hero video, galleries, modals, and embeds, and each one brought its own values. I counted what was actually in the 1,363-line stylesheet.

9named variables in :root
58different color values in the stylesheet
22different font sizes
8different border radii

All 58 color values found in styles.css. 19 of them are white at a different opacity.

Process

Four steps, in order

  1. 01 · Audit

    Count what exists

    Extracted every color, font size, radius, and spacing value from the stylesheet and grouped the near-duplicates.

  2. 02 · Primitives

    Collapse into scales

    Paper, ink, and ember ramps, plus the two logo colors, which had never been written down as values.

  3. 03 · Semantic

    Name by purpose

    Tokens like color.accent.on-light point to a primitive. Components only read this layer.

  4. 04 · Components

    Prove it on real UI

    Rebuilt the nav, section headers, cards, and stats on both paper and ink surfaces from tokens alone.

Accessibility decision

One accent, two tokens

The site used a single --accent everywhere. On charcoal it reads at 5.0:1. On paper the same orange drops to 2.5:1, well under the 4.5:1 AA minimum for text. The fix was a second token for light surfaces that keeps the hue and passes.

What goes into the code

Tokens are written in the W3C Design Tokens Community Group format. Semantic tokens hold a reference to their primitive instead of a hex, so the chain survives into the stylesheet.


    

  


  

    Takeaways
    
What I learned

    

      
Audit before you design
I expected to invent a palette. Almost every value I needed was already in the site. The work was choosing which ones to keep and putting them in order.

      
An accent depends on its surface
One --accent variable looked consistent and wasn’t. Splitting it by surface fixed contrast on every paper section at once.

      
Opacity is not a color system
Nineteen opacities of white came from adjusting each overlay by eye. Five named steps cover all of them and make the next one an easy choice.
