Stay Scout:
from a logo to a token system

Stay Scout arrived with a single file: its logo. I built the token system that turns that coral into buttons, cards, readable text, and a dark mode, ready for engineering to use without guessing.

Role
UI/UX design
Scope

Year

Starting point

One logo, one color, no rules

Without brand guidelines, every new screen would invent its own coral, its own gray, and its own corner radius. The goal was to pull every possible decision out of the logo and name it, so the team would never have to make it again.

Process

Three layers, each with one job

  1. 01 · Extract

    Read the logo

    I sampled the coral and the cream background. The rounded shapes of the pin and wordmark set the radius and the typeface.

  2. 02 · Primitives

    Color scales

    A 10-step coral scale built around the logo color, plus warm neutrals for backgrounds and text.

  3. 03 · Semantic

    Name by purpose

    Tokens like color.action.primary point to a primitive. Components only use this layer.

  4. 04 · Components

    Test and ship

    Search bar and stay cards in light and dark, plus the JSON and CSS export for engineering.

Layer 1 · Primitives

The coral scale

The logo coral is step 500. Light steps handle backgrounds and tags; dark steps carry text and buttons where 500 can’t reach the required contrast.

Accessibility decision

The logo coral doesn’t carry text

With white text, coral 500 only reaches 3.2:1, below the 4.5:1 AA minimum. That’s why brand and action are separate tokens: the logo keeps its coral, and buttons use 600, which keeps the hue and passes contrast.

Layer 3 · Components

Same components, two themes

No component knows which color it uses. Dark mode only changes which primitive the semantic tokens point to.

action.primary → coral.600 · bg.page → sand.100

Handoff

What engineering receives

Tokens export in the W3C Design Tokens Community Group format. Semantic tokens keep a reference to their primitive instead of a hex value, so the chain survives into code.


    

  


  

    Takeaways
    
What I learned

    

      
Separate brand from action
A brand’s most recognizable color isn’t always the one that can carry text. Giving it two tokens prevented a contrast problem on every button.

      
Name by purpose, not by color
action.primary survives a rebrand; coral-button doesn’t. The name is the longest-lasting part of the system.

      
Dark mode comes almost free
With a solid semantic layer, the dark theme meant redefining about a dozen tokens without touching a single component.
