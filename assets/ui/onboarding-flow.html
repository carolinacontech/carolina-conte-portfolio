Stay Scout: the first three minutes

Three questions, a shortlist, then the account. The flow is live: answer in the phone and watch the number of matching stays narrow with every choice.

  1. One promise and one action. Signing in is a quiet second option, because returning guests already know what they are looking for.

  2. The first question is one anyone can answer in two seconds. The match count appears here and stays in the same place until the end, so each answer has a visible result.

  3. Up to three. The limit makes people rank what matters, which produces better matches than ten ticked boxes. This step is optional and the button says so.

  4. Hours behind the wheel, not miles, because that is how a weekend gets planned. Location is requested at the moment it is useful, with a typed city as the default path.

  5. Results come before sign-up. Each card repeats the guest's own must-haves, so the questions are shown to have counted.

  6. The account is requested once there is something worth keeping, and it costs one field. Password and profile wait for the second visit.
